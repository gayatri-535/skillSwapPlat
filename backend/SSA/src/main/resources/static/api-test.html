📚 API Documentation

// User Endpoints
POST   /api/users/register          - Register new user
POST   /api/users/login             - Login with email & password  
GET    /api/users                   - List all active users
GET    /api/users/{email}           - Get user by email

// Swap Endpoints
POST   /api/swaps                   - Create swap request
GET    /api/swaps                   - List all swaps
GET    /api/swaps/{id}              - Get swap by ID
GET    /api/swaps/user/{userId}     - List user's swaps
POST   /api/swaps/{id}/accept       - Accept swap request
POST   /api/swaps/{id}/cancel       - Cancel swap request

// Example Request (Register)
POST /api/users/register
Content-Type: application/json

{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "securePassword123",
  "location": "San Francisco",
  "availability": "weekends",
  "isPublic": true,
  "isBanned": false
}

// Example Request (Create Swap)
POST /api/swaps
Content-Type: application/json

{
  "requesterId": 1,
  "receiverId": 2,
  "requestedSkill": "Python Programming",
  "offeredSkill": "Web Design",
  "status": "pending"
}
